# Knowledge Base di Experience Manager Guides

La Knowledge Base contiene articoli pratici e basati su scenari per Experience Manager Guides che descrivono configurazioni, personalizzazioni e casi d’uso comuni oltre alla documentazione di base del prodotto.

| Categoria | Descrizione |
|---|---|
| Authoring | Suggerimenti e tecniche per la creazione e il riutilizzo di contenuti nell&#39;editor, incluse personalizzazioni dell&#39;editor, gestione dei metadati e convalida dei contenuti. |
| Framework di estensione delle guide | Scopri come personalizzare l’interfaccia utente di Experience Manager Guides, dalla guida introduttiva al framework delle estensioni fino alla creazione di componenti personalizzati, widget e personalizzazioni delle app di revisione. |
| Source dati esterno | Linee guida sull’integrazione e la configurazione di connettori per origini dati esterne con Experience Manager Guides. |
| Pubblicazione | Best practice per la generazione di output, tra cui PDF nativo, DITA-OT, modelli AEM Sites e configurazioni di pubblicazione basate su microservizi. |
| Flussi di lavoro | Configura e utilizza flussi di lavoro di post-generazione per automatizzare i passaggi dopo la produzione dell’output. |
| Traduzione | Istruzioni su come migliorare le prestazioni di traduzione e gestire quali contenuti includere o escludere dalla traduzione. |
| Casi d’uso | Scopri scenari reali come il contenuto condizionale, l’utilizzo di chiavi e variabili di contenuto contestuale nell’output pubblicato. |
